Rush Observability is installed.

1. Watch the application start:

   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} --watch

2. Read the generated admin password:

   kubectl -n {{ .Release.Namespace }} get secret {{ .Values.rush.queryApi.config.secrets.existingSecret | default (printf "%s-bootstrap" .Release.Name) }} -o jsonpath='{.data.initial-admin-password}' | base64 -d; echo

3. Open the UI:

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-frontend 8080:80

   Visit http://localhost:8080 and sign in as admin.
